# Verdant — Sustainability Platform Landing Page

A standalone, responsive landing page concept for a fictional climate-intelligence
platform. Built with semantic HTML, custom CSS, vanilla JavaScript, and locally
hosted fonts. No build step or external runtime dependencies.

## Run it

From this folder:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Then open <http://127.0.0.1:4173>.

You can also open `index.html` directly, though a local server is recommended so
the local font files load consistently.

## What's included

- Organic biophilic art direction with a warm bone, forest, sage, clay, and ochre palette.
- Hero carbon-footprint calculator preview with live estimates and a segmented home-energy control.
- Animated impact metrics that count up when they enter the viewport.
- Measure / Reduce / Prove product feature bento.
- Customer quote and quantified result.
- Six illustrated certification seals.
- Conversion section with email validation and a success state.
- Sticky header, accessible mobile navigation, scroll reveals, and reduced-motion support.
- Local Fraunces, Instrument Sans, and DM Mono font files for offline use.
